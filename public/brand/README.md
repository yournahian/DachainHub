# Brand Assets Folder

Please upload your icons, logos, and favicon assets here.

Recommended files:
- `favicon.svg` (for the browser tab icon, supports light/dark CSS transitions)
- `logo-light.svg` (for the main header logo in light theme)
- `logo-dark.svg` (for the main header logo in dark theme)
- `icon-512.png` (high-res fallback for mobile devices and social sharing tags)

Once you upload the files to this folder, let me know and I will update the configuration to point to them!
